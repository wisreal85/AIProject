# 오늘의 놀이 (KidsPlayGuide)

1~3세(12~36개월) 아이를 키우는 부모를 위한 **무료 놀이 가이드 앱**의 Unity 프로젝트입니다.
앱을 켜면 아이 월령에 맞는 오늘의 놀이 3개와 진행 방법, 부모가 할 말을 보여 줍니다.
아이가 보는 앱이 아니라 부모가 보는 앱이라 영아 스크린 타임 걱정이 없습니다.

## 여는 방법

1. Unity Hub → **Add project from disk** → 이 `KidsPlayGuide` 폴더 선택
2. Unity **2022.3 LTS 이상**으로 엽니다 (Unity 6 도 가능, 열 때 업그레이드 확인만 누르면 됩니다).
3. 처음 열면 `Assets/Editor/ProjectSetup.cs` 가 `Assets/Scenes/Main.unity` 를 만들고 빌드 목록·앱 이름·세로 고정을 맞춥니다.
4. **Play** 를 누릅니다. Game 뷰 해상도는 1080×1920(세로)을 권합니다.

씬·프리팹 연결이 없습니다. `App` 이 실행 시점에 스스로 생성되어 화면 전체를 코드(uGUI)로 그립니다.

## 화면

| 화면 | 내용 |
| --- | --- |
| 아이 등록 | 이름, 생년월일 → 월령 계산 |
| 홈 | 월령에 맞는 오늘의 놀이 3개 (발달 영역이 겹치지 않게, 최근 한 놀이는 뒤로) |
| 놀이 상세 | 준비물, 단계별 방법, 부모 말 가이드, 도움말, 주의, 근거 |
| 기록 | 했어요 체크, 아이 반응, 메모, 최근 30일 영역별 횟수 |
| 수면 | 백색·분홍·갈색 소음, 자장가 2곡, 음량, 꺼짐 타이머 |
| 부모 | 아이 정보 수정, 후원(준비 중), 근거와 한계, 데이터 지우기 |

## 구조

```
Assets/
  Resources/plays.json          놀이 콘텐츠 30개 (월령 구간 4개 × 발달 영역 5개)
  Scripts/Data/PlayModels.cs    놀이 데이터 모델, 월령별 조회
  Scripts/Core/AppState.cs      저장(기기 로컬 JSON), 월령 계산, 오늘의 놀이 선정
  Scripts/Audio/SleepAudioPlayer.cs  수면 소리 합성·타이머
  Scripts/UI/UI.cs              uGUI 요소 생성 도우미
  Scripts/UI/App.cs             진입점과 모든 화면
  Editor/ProjectSetup.cs        최초 1회 프로젝트 설정
```

## 놀이 콘텐츠 추가

`Assets/Resources/plays.json` 에 항목을 추가하면 됩니다. 코드 수정은 필요 없습니다.

```json
{
  "id": "a9", "title": "놀이 이름", "minMonths": 12, "maxMonths": 17,
  "domain": "gross | fine | language | cognition | social", "minutes": 10,
  "materials": ["준비물"], "steps": ["1단계", "2단계"],
  "parentTalk": ["부모가 할 말"], "tip": "도움말", "caution": "주의 (없으면 빈 문자열)",
  "source": "근거 출처"
}
```

## 원칙

- **무료**: 구독, 맞춤 광고, 결제 유도가 없습니다.
- **개인정보 최소화**: 아이 이름·생년월일·기록은 기기(`Application.persistentDataPath/save.json`)에만 저장하고 어디로도 보내지 않습니다.
- **저작권**: 수면 소리는 음원 파일 없이 코드로 합성합니다. 자장가는 저작권이 만료된 선율(브람스 자장가, 작은 별)입니다.

## 알아 둘 점

- 놀이 내용은 K-DST(한국 영유아 발달선별검사)의 월령 구간과 발달 영역을 참고해 만든 **AI 초안**입니다. 전문가 감수를 받지 않았으니 출시 전에 직접 검수가 필요합니다.
- 한글은 OS 글꼴(Apple SD Gothic Neo, 맑은 고딕, Noto Sans CJK KR 등)로 표시합니다. WebGL 처럼 OS 글꼴이 없는 플랫폼은 한글 글꼴 파일을 프로젝트에 넣어 `UI.LoadFont` 에서 불러와야 합니다.
- 모바일에서 화면이 꺼지거나 앱이 백그라운드로 가면 소리가 멈춥니다. 백그라운드 재생은 플랫폼별 네이티브 설정이 필요합니다.
